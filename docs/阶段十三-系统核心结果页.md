# 阶段十三：系统核心结果页

## 1. 本阶段范围

本阶段实现旅行方案的核心结果工作台，包括方案切换与比较、地图路线、每日
时间线、预算分析、冲突处理、证据查看、版本化重规划、候选方案确认和费用
操作人工确认。结果页以单个方案为数据边界，所有业务模块始终读取同一份
方案投影。

同时完成全站用户文案治理：页面不展示运行模式、协议名称、内部资源标识、
状态码或服务端原始异常。诊断数据仍保留在内部状态、日志和链路中，不进入
普通用户界面。

## 2. 完成项

### 2.1 结果页布局

- 桌面端采用三栏结构：左侧为旅行约束、候选方案和版本历史，中间为地图与
  每日时间线，右侧为预算、冲突、证据及确认操作。
- 移动端使用地图、时间线、预算和冲突四个模块切换，方案选择与版本入口位于
  内容顶部，比较和重规划操作固定在底部。
- 移动端默认折叠旅行约束，地图在首屏保留足够可见区域。
- 桌面和移动端均无横向溢出，紧凑控制区中的标题、选项和按钮不会相互遮挡。

### 2.2 方案与版本

- 同一旅行的候选方案可快速切换，按方案家族判断当前候选，避免不同版本造成
  错误高亮。
- 比较抽屉支持两个方案并排查看总费用、每日强度、通勤时间、景点数量和证据
  覆盖，并解释各方案适合的旅行偏好。
- 版本历史按方案家族独立展示，版本比较使用独立查询缓存。
- 当前旅行和当前方案写入本地恢复索引；刷新后仍从后端重新读取方案事实。

### 2.3 地图与时间线

- 地图只使用后端返回的经纬度，不在浏览器中地理编码或推测坐标。
- 不同日期使用不同路线颜色；缺少有效坐标时给出可理解的降级状态。
- 点击地图地点会选中对应时间线条目，点击时间线条目会聚焦地图地点。
- 地图瓦片通过 Spring Boot 代理和 generated `MapsApi` 获取，浏览器不直连
  地图供应商。
- 地图控件、缩放按钮和协作手势提示均使用中文无障碍文案。
- 时间线展示时间、地点、活动、交通、停留时长、费用、来源和推荐理由，并
  支持锁定和标记删除。

### 2.4 预算、冲突与证据

- 预算模块使用 ECharts 展示分类柱图，并展示总预算、预计总费用、剩余金额、
  使用率和超预算原因。
- 金额与币种直接使用当前方案数据，不在前端转换或补造业务金额。
- 冲突中心展示严重级别、冲突对象、业务规则分类、修复建议和已解决历史。
- 冲突建议可直接带入重规划，已锁定项目继续保留。
- 证据抽屉展示来源标题、摘要、更新时间和检索策略，并区分公共知识、用户
  记忆、实时信息和关系信息。
- 外链只允许 `http` 或 `https`；没有有效链接时不创建跳转。

### 2.5 重规划与人工确认

- 支持自然语言修改、预算与节奏调整、新增偏好、锁定条目和删除条目。
- 重规划提交后创建新版本，不覆盖当前版本，并在完成后进入新的方案结果。
- 候选方案确认只保存用户选择，不创建订单或触发支付。
- 费用相关操作必须在独立确认面板中展示金额、币种、风险、有效期和影响
  范围，用户明确勾选后才能确认。
- 确认、拒绝和重规划均使用幂等键，并提供提交中、成功、失败和重试状态。

### 2.6 用户文案与错误边界

- 顶部导航移除“后端已连接”“后端离线”和 `MOCK` 等实现文字。
- 演示环境仅显示“当前展示演示数据”，不把演示内容解释为真实供应商结果。
- 侧栏、进度页、资料页和结果页不显示 `traceId`、`taskId`、`planId`、SSE、
  轮询方式、内部枚举、规则码或字段路径。
- 进度页使用固定的业务阶段名称和安全摘要，不直接渲染服务端事件消息、
  Agent 原始摘要或警告原文。
- 全局错误按 401、403、404、409、422、429 和 5xx 映射为用户可理解的
  恢复建议；服务端 `message` 不直接进入通知或错误页。
- 422 仍通过结构化字段路径定位表单项，但页面只显示统一字段提示。
- 状态标签未知值统一显示“状态更新”，不通过标题属性泄露内部枚举。

## 6. 接口调用示例

读取同一旅行的方案并比较版本：

```bash
curl http://localhost:8080/api/v1/trips/<trip-id>/plans

curl \
  http://localhost:8080/api/v1/plans/<plan-id>/compare/<other-plan-id>
```

创建不覆盖旧版本的重规划：

```bash
curl -X POST http://localhost:8080/api/v1/plans/<plan-id>/replan \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: replan-example-0001' \
  -d '{
    "reason":"减少跨区移动",
    "naturalLanguageRequest":"保留已确认住宿，第二天下午安排休息",
    "lockedItemIds":["<locked-item-id>"],
    "removedItemIds":["<removed-item-id>"],
    "adjustedTotalBudget":6000,
    "adjustedPace":"RELAXED",
    "addedPreferences":["胡同历史"]
  }'
```

确认候选方案：

```bash
curl -X POST http://localhost:8080/api/v1/plans/<plan-id>/confirm \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: plan-confirm-example-0001' \
  -d '{"expectedVersion":2}'
```

涉及费用的动作必须先创建候选，再使用动作版本、金额和币种进行确认：

```bash
curl -X POST http://localhost:8080/api/v1/actions \
  -H 'Content-Type: application/json' \
  -H 'X-Actor-Id: <actor-id>' \
  -H 'Idempotency-Key: action-propose-example-0001' \
  -d '{
    "type":"ORDER_CREATE",
    "resourceId":"<plan-id>",
    "riskDescription":"价格、库存和取消条款可能变化",
    "amount":5600,
    "currency":"CNY",
    "expiresAt":"2026-09-07T14:30:00Z"
  }'
```

## 7. 遗留问题

- MapLibre 和主入口生产 Chunk 仍超过 500 KiB，当前不影响正确性；后续应
  继续拆分地图 Worker、图表和结果页依赖，并以真实网络指标验证收益。
- 默认公共地图瓦片源只适合开发和低流量验收；生产环境需配置合规的专用或
  自托管瓦片源，并保持浏览器只访问后端代理。
- 当前费用确认只记录受控候选授权，不调用真实商家、不创建订单、不扣款。
- 反馈与质量评测管理页面、真实交易供应商适配器和远程 A2A 部署仍属于后续
  阶段。
