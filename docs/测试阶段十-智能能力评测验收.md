## 1. 验收结论

本阶段已完成固定合成数据集上的三轮 Mock 基线采集，7/7 个执行批次通过，
每轮 14/14 项 Java 证据测试通过，OCR、RAG、Agent 和行程质量指标均完成

## 5. 可重复性

三轮的所有已测指标值均完全一致，最小值、最大值和均值相同，总体标准差均为 0。
这证明当前固定 seed 和 Mock 实现可重复，但不能推出真实模型也无波动。每轮均重新：

1. 创建隔离的 LanceDB 运行目录并采集 11 个 OCR、10 个 RAG 用例；
2. 删除旧 Java 基线报告；
3. 运行 6 个 Java 测试类、14 个测试方法；
4. 复制该轮新生成的 Java 评测报告并解析独立 JUnit。

## 6. 失败案例

RAG 隔离负例没有发现禁用证据，用户记忆隔离率为 3/3。Mock OCR 的其余复杂图片
场景得分不能解释为像素鲁棒性，因为 Mock provider 按测试文件名返回固定结构。
