# 阶段十二：旅行创建主流程与后端联调

## 1. 本阶段范围

本阶段实现产品首页、八步旅行需求向导、订单资料中心和 Agent 生成控制台。
所有业务数据均来自 Spring Boot 公共 API；浏览器不直接请求模型、地图
供应商、天气、检索、MCP 或 FastAPI。

## 2. 完成项

### 2.1 产品首页

- 使用 MapLibre 和后端代理的 OpenStreetMap 世界地图构成首屏背景，浏览器
  不直接请求外部地图服务。
- 展示 TripAgent Nexus 品牌、核心价值、开始规划和示例模板入口。
- 最近行程只保存真实后端 `tripId`，展示时逐项回读后端，不使用伪造列表。
- 没有历史行程时显示明确空状态。

### 2.2 旅行需求向导

- 实现路线、日期人数、预算、兴趣、节奏、偏好、同行人员和确认八个步骤。
- 使用 React Hook Form 与 Zod 执行日期范围、人数、预算、币种和字段长度
  预校验，最终仍以后端校验为准。
- 使用 Zustand 持久化未完成草稿、当前步骤、用户 ID 和两个幂等键。
- 创建旅行成功但需求保存失败时保留真实 `tripId`，重试不会重复创建旅行。
- 将后端 422 `details[].field` 的 RFC 6901 路径映射到具体表单字段。
- 示例入口只预填表单，不把样例数据当作接口成功结果。

### 2.3 订单资料中心

- 支持拖放与文件选择，前端预校验 PNG、JPEG、WEBP、PDF 和 10 MB 上限。
- 上传请求先通过 generated SDK 构造，再由统一 Adapter 使用 XHR 获取真实
  上传字节进度。
- 浏览器计算 SHA-256，在当前旅行内提示已知重复文件；后端仍执行最终重复
  校验。
- 展示后端任务进度、文档状态、提取字段、总体/字段置信度和规则问题。
- 低于 0.75 的字段及 `LOW_CONFIDENCE`、`MISSING` 字段高亮。
- 展示脱敏原文证据、页码与归一化区域；当前会话有图片预览时叠加区域框。
- 支持按 generated `BookingField` 提交人工修正，并携带 Actor 与幂等键。
- 解析失败可调用新的后端重试接口，不需要浏览器再次上传原文件。

### 2.4 Agent 生成控制台

- 方案创建返回的 `taskId`、`resourceId` 和 `traceId` 持久化到浏览器。
- 页面刷新或直接访问 `/tasks/{taskId}` 时从后端恢复任务。
- 使用后端 `TaskRecord`、SSE `TaskEvent` 和 Agent 执行投影展示真实进度。
- SSE 正常结束或断开后读取轮询终态，不使用前端计时器递增进度。
- 展示需求载入、检索、Agent/工具、候选、规则审校、局部重规划和完成阶段。
- 展示八个 Agent 的状态、后端实测耗时、结果摘要、证据数量和警告。
- 页面只显示业务摘要，不展示 `taskId`、`traceId`、连接方式、任务类型、
  原始事件消息或服务端异常。

### 2.5 后端契约增量

- `GET /api/v1/maps/tiles/{zoom}/{x}/{y}.png`
  在坐标校验、域名白名单、响应类型和大小限制下代理真实世界地图瓦片。
- `GET /api/v1/tasks/{taskId}/agents`
  返回后端持久化的逐 Agent 执行投影。
- `POST /api/v1/documents/{documentId}/retry`
  为失败文档创建新的 `retryOfTaskId` 任务并重新投递解析。
- A2A 委派开始和结束时写入现有 `agent_result` 表；不保存完整 Prompt、
  模型原文或用户上下文，只保存安全摘要、耗时、证据数量和警告。
- 修复 `ExtractedFieldEvidence` 的 OpenAPI 生成兼容性，generated SDK
  现在完整包含字段、置信度、文字证据和区域类型。

## 6. 接口调用示例

创建旅行并保存需求：

```bash
curl -X POST http://localhost:8080/api/v1/trips \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: trip-create-example-0001' \
  -d '{"userId":"<user-id>","title":"杭州周末","timeZone":"Asia/Shanghai"}'

curl -X PUT http://localhost:8080/api/v1/trips/<trip-id>/requirements \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: requirement-example-0001' \
  -d '{
    "origin":{"name":"上海"},
    "destinations":[{"name":"杭州"}],
    "startDate":"2026-10-01",
    "endDate":"2026-10-03",
    "travelers":[{"travelerId":"<traveler-id>","displayName":"旅行者 1","type":"ADULT","accessibilityNeeds":[]}],
    "totalBudget":5000,
    "currency":"CNY",
    "interests":["本地美食"],
    "pace":"BALANCED",
    "mustVisit":["西湖"],
    "avoid":[],
    "freeTextConstraints":"每天保留午休时间"
  }'
```

文档失败重试与 Agent 执行详情：


## 7. 遗留问题

- 冻结 API 没有按用户列出旅行和按旅行列出文档的接口；前端目前只登记本机
  创建或上传过的资源 ID，再逐项回读真实后端。跨设备历史列表需以后续新增
  的可分页接口实现。
- 完整方案详情、方案对比、重规划、确认和反馈页面不在本阶段范围内。
- MapLibre 已通过 Spring Boot 代理读取真实地图瓦片。默认公共瓦片源适合
  开发和低流量验收；生产环境需配置专用或自托管瓦片源，并遵守供应商缓存、
  署名和流量策略。
- 当前机器 Docker/Colima 未运行。旅行创建和方案生成已使用真实 Spring
  Boot 与临时 PostgreSQL 完成跨进程浏览器联调；依赖 Kafka 的 OCR 浏览器
  场景使用契约级网络夹具，并由 Spring Boot Embedded Kafka 集成测试验证。
- MapLibre 主 Chunk 仍较大，虽已动态加载，后续可评估更细的 Worker 拆分。
