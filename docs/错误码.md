# API 错误契约

所有公共 API 错误使用 `application/json`：

```json
{
  "code": "IDEMPOTENCY_KEY_REUSED",
  "message": "该幂等键已用于不同请求。",
  "details": [
    {
      "field": "/title",
      "code": "FIELD_INVALID",
      "message": "不得为空"
    }
  ],
  "traceId": "4bf92f3577b34da6a3ce929d0e0e4736",
  "timestamp": "2026-09-03T06:30:00Z"
}
```

规则：

- `code` 稳定并用于客户端分支。
- `message` 可安全展示，不包含实现细节。
- `details[].field` 在适用时使用 RFC 6901 JSON Pointer。
- `traceId` 为 32 位小写 OpenTelemetry Trace ID。
- `timestamp` 为 RFC 3339 UTC。
- 不返回堆栈、SQL、文件内容、密钥、Authorization、Cookie、Prompt 或
  模型输出。

## 通用、旅行与反馈

| 错误码                         | HTTP | 含义                         |
| ------------------------------ | ---: | ---------------------------- |
| `REQUEST_INVALID`              |  400 | 请求、路径或 Header 无法解析 |
| `CONTENT_TYPE_UNSUPPORTED`     |  415 | 请求内容类型不受支持         |
| `METHOD_NOT_ALLOWED`           |  405 | 资源不支持该 HTTP 方法       |
| `FIELD_INVALID`                |  422 | 单个字段不符合约束           |

| `IDEMPOTENCY_KEY_INVALID`      |  400 | 幂等键缺失或格式非法         |
| `IDEMPOTENCY_KEY_REUSED`       |  409 | 幂等键被不同请求复用         |
| `AUTHENTICATION_REQUIRED`      |  401 | 缺少有效用户会话             |
| `RESOURCE_NOT_FOUND`           |  404 | 资源不存在或不属于当前用户   |
| `RESOURCE_CONFLICT`            |  409 | 数据库或乐观锁冲突           |
| `TRIP_NOT_FOUND`               |  404 | 旅行不存在                   |
