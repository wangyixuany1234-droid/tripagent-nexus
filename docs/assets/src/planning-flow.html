有界重试与死信
Kafka、模型、外部 HTTP 与 A2A 重试均有最大次数、超时与最大退避；耗尽后进入持久化死信，不存在无限重试。
重启任务恢复
重启只重派安全的排队或显式可重试阶段；不安全的运行中步骤失败为 TASK_RECOVERY_UNSAFE。
SSE 断线回放
任务事件先写 PostgreSQL 再广播并缓存 Redis；断线用 Last-Event-ID 回放，Redis 丢失不造成进度缺口。
