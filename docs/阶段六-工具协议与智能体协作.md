# 阶段六：MCP 与 A2A 多智能体

## 完成项

- 为八个 Agent 定义独立 Card、输入、输出、Prompt 版本和重试策略。
- 使用 MCP Java SDK 2.0.1 提供 `/mcp` Streamable HTTP。
- MCP 强制 Bearer 鉴权、Agent 身份、Skill 白名单、输入 Schema 和负载上限。
- 工具包括 `place_search`、`weather_query`、`route_calculate`、
  `exchange_rate`、`opening_hours`、`booking_parse`、`budget_validate`、
  `itinerary_store`。
- 使用 A2A Java SDK 1.3.0.Final 实现发现、委派、任务状态和结果制品。
- Requirement、Research、Transport、Accommodation、Recommendation、
  Budget、Review、Coordinator 分别实现，未堆叠到单个类或 Prompt。
- `ContextEnvelope` 按职责、隐私标签和 Token 预算裁剪。
- Coordinator 把交通到达时间传给住宿 Agent，并用 `BigDecimal` 聚合费用。

## 启动

```bash
SPRING_PROFILES_ACTIVE=local,mock-model \
MCP_PROVIDER_MODE=MOCK \
MCP_SERVICE_TOKEN="$(openssl rand -hex 32)" \
mvn -pl apps/trip-agent-api spring-boot:run
```

## MCP 示例

```bash
curl -fsS http://localhost:8080/mcp \
  -H "Authorization: Bearer ${MCP_SERVICE_TOKEN}" \
  -H "X-Agent-Name: BudgetAgent" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  --data '{"jsonrpc":"2.0","id":"tool-1","method":"tools/call","params":{"name":"budget_validate","arguments":{"currency":"CNY","budgetLimit":100,"items":[{"category":"FOOD","description":"Dinner","amount":80,"currency":"CNY"}]}}}'
```

## A2A 示例

```java
delegationService.discover(Set.of("route_calculate"));
AgentResultEnvelope<JsonNode> result =
    delegationService.delegate(AgentName.TRANSPORT, input, tenantId);
Task task =
    delegationService.taskStatus(
        AgentName.TRANSPORT, result.taskId().toString(), tenantId);
```

## 测试

```bash
mvn -pl apps/trip-agent-api \
  -Dtest='AgentSchemaValidatorTest,ContextEnvelopeReducerTest,A2ADelegationServiceTest,ItineraryArtifactServiceTest,AgentOrchestrationIntegrationTest' \
  test
```

FastAPI pytest 额外检查共享 MCP/A2A Schema 的工具集合、闭合输入、幂等性、
独立 Agent 文件、有限重试、超时和隐私标签。

## 限制

- A2A 当前同进程部署，后续可替换为官方远程 JSON-RPC 传输。
- 天气、路线、汇率和营业时间真实供应商未配置时返回 `UNAVAILABLE`。
- Mock 工具必须返回 `providerMode=MOCK` 和警告。

## 验收

八个 Agent 可发现且独立，MCP 初始化和预算工具可调用，A2A 委派有界，
上下文最小化，结构化输入输出和行程存储幂等均有自动化测试。
